Analyst approach

Make the result explainable.

A correct calculation starts with a clear grain and a defensible denominator.

  1. 01

    Define

    State the decision, record grain and metric definitions.

  2. 02

    Inspect

    Check missing values, duplicates, keys and source relationships.

  3. 03

    Reconcile

    Compare totals with source facts and test important edge cases.

  4. 04

    Explain

    Describe findings, uncertainty and an actionable next step.

These are independent portfolio demonstrations. Synthetic findings and scenario costs are not employer results or realized savings. Recent code and documentation improvements were developed with AI assistance; documented checks should be reviewed and rerun before reuse.
